🚗 Motorvognregisteret
Motorvognregisteret is a simple web application built with Spring Boot that allows users to register motor vehicles along with owner information via a web interface.
This project is intended as a learning/demo application and follows a classic Spring Boot + HTML + JavaScript structure.

✨ Features
Register motor vehicles with owner details
Simple HTML form frontend
Backend built with Spring Boot (Java)
REST-style controller handling requests
Static frontend served from Spring Boot
Uses Bootstrap for basic styling

🛠️ Tech Stack
Java
Spring Boot
Maven
HTML / CSS
JavaScript
Bootstrap 3
jQuery


1️⃣ Clone the repository
git clone https://github.com/Abdisharif107/Motorvognregisteret.git

2️⃣ Navigate into the project
cd Motorvognregisteret

3️⃣ Run the application
./mvnw spring-boot:run
(On Windows: mvnw.cmd spring-boot:run)

4️⃣ Open in browser
Once the app is running, open:
http://localhost:8080

🧾 Application Description
The frontend consists of an HTML form where users can enter:
Personal number
Name
Address
Vehicle characteristics (such as brand, model, etc.)
The data is handled by a Spring Boot controller and mapped to a Motorvogn model class.

🎯 Purpose
This project is mainly created for:
Learning Spring Boot basics
Understanding MVC / REST controllers
Practicing frontend ↔ backend interaction
School or coursework assignments
